# 牧場 × クローバー × お花 × フリル × ハート × レース 汎用動画素材

ピンク・黄色・黄緑のパステル系で統一した、ゆめかわ・ロリータ・乙女テイストの動画素材セット。すべて 30fps。
パールのキルティング・レースのドイリー・チュール・パールの飾り鎖・リボン・バラ・ティアラ・宝石ハート・シャボン玉・パステルの虹・ラメを散りばめている。

| ファイル (`out/`) | 内容 | サイズ / 長さ | 背景 |
|---|---|---|---|
| `ranch_loop.mp4` / `.webm` | 牧場の背景（パステルの虹・ハートの雲・ティアラのお日さま・レース帽の羊・パール鎖の柵・宝石ハートの納屋・クローバー畑・お花・シャボン玉） | 1920×1080 / 8秒ループ | あり |
| `frill_frame_transparent.webm` ほか `_yellow` `_green` | **フレーム**：パールのキルティング地に、フリル＋チュール＋レース。上はティアラと大きいリボン＋パールの飾り鎖、四隅はドイリーにバラ・クローバー・リボンの花束 | 1920×1080 / 6秒ループ | 中央透過 |
| `heart3d_transparent.webm` | **3Dモデル**：虹色にきらめくぷっくりハート（ティアラ・リボン・フリル付き）がくるっと回り、周りをクローバー・星・お花・シャボン玉・リボン・ハート・パールのネックレスが回る | 1080×1080 / 6秒ループ | 透過 |
| `falling_transparent.webm` / `falling_up_transparent.webm` | ハート・宝石ハート・クローバー・お花・バラ・リボン・星・パール・ティアラ・シャボン玉・花びらが降る / 下から昇る | 1920×1080 / 8秒ループ | 透過 |
| `frill_transition_transparent.webm` | フリル＋チュール＋レースの布（ピンクはキルティングにバラと宝石ハート）が緑→黄→ピンクの順に降りてきて画面をおおい、下へ抜けるトランジション（0.6〜1.25秒は全面がかくれるので 0.9秒ごろでカットをつなぐ） | 1920×1080 / 2秒 | 透過 |
| `plant_grow_transparent.webm` | 画面の下の両すみからツルが伸びて葉っぱ・クローバー・リボン・宝石ハートが出て、先にバラが咲く（伸びきったあとは揺れる） | 1920×1080 / 6秒 | 透過 |
| `pattern_loop.mp4` / `.webm` ほか `_yellow` `_green` | パールのキルティング地に、ドイリーにのったバラ・宝石ハート・リボン・ティアラ・クローバーの柄がななめに流れ、上下にフリル＋チュール＋レース | 1920×1080 / 6秒ループ | あり |

- 透過素材は **WebM (VP9 アルファ付き)** と **`*_purpleback.mp4`（パープルバック #8000FF）**。パープルバックはクロマキーで紫を抜いて使う
- シャボン玉・チュールなど半透明の部分は、パープルバックだと紫がまざるので、きれいに透かしたいときは透過 WebM を使う。キー色は `KEY=0xRRGGBB` で変えられる
- 透過 MOV (ProRes 4444) がほしいときは `PRORES=1` を付けて書き出す
- `*_thumb.png` は各素材の途中のコマ

## 作り直し方

各素材は `src/*.html`（Canvas 2D / 3D は three.js）。パーツは `src/motifs.js`（ハート・クローバー・デイジー・小花・チューリップ・葉っぱ・リボン・パール・フリル・レース・ギンガム・バラ・宝石ハート・ティアラ・星・シャボン玉・パール鎖・ドイリー・チュール・キルティング・ラメ）。

```
# リポジトリ直下で
python3 -m http.server 8765 &
node ranch_motif/src/render.mjs ranch_loop            # → ranch_motif/out/ranch_loop.mp4 / .webm
node ranch_motif/src/render.mjs frill_frame yellow    # #yellow 版
node ranch_motif/src/render.mjs heart3d --still 1.5   # 1.5秒のコマを PNG で 1 枚だけ
PRORES=1 node ranch_motif/src/render.mjs heart3d      # 透過 MOV も書き出す
```

ブラウザで `http://localhost:8765/ranch_motif/src/frill_frame.html#green` のように開くと、その素材の 1 コマ目を確認できる。
