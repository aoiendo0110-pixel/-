# 乙女3D素材（グリーンバック）

three.js で作った乙女モチーフ3Dモデルのループ動画素材。背景は #00FF00 のグリーンバック。

- 1920×1080 / 30fps / 4秒（頭と終わりがつながるシームレスループ）/ H.264 mp4
- `videos/` に 01〜09 が単体、10 が全部入りの集合版
- `contact_sheet.png` で一覧が見られる

| No | モチーフ | 動き |
|---|---|---|
| 01 | リボン（ステッチ入りサテン＋パール） | ゆらゆら首振り |
| 02 | フリルハート＋レースドイリー | ゆらゆら首振り |
| 03 | いちごのデコケーキ（ドリップ・フリル皿） | くるっと一回転 |
| 04 | リップスティック | くるっと一回転 |
| 05 | ハート型の香水瓶 | くるっと一回転 |
| 06 | 猫脚ドレッサー（楕円ミラー） | ゆらゆら首振り |
| 07 | リボン付きいちご | くるっと一回転 |
| 08 | さくらんぼ | くるっと一回転 |
| 09 | マカロンタワー | くるっと一回転 |
| 10 | 全部入り | それぞれふわふわ |

クロマキー抜けを防ぐため、緑色のパーツ（いちごのヘタなど）は使わず、ヘタはリボンに置き換えている。
02 のレースは穴の部分がグリーンなので、キーイングすると透けたレースになる。

## 書き出し方
```
node render.js <obj> <出力フォルダ> 30 4        # PNG連番
ffmpeg -framerate 30 -i <出力フォルダ>/f%04d.png -c:v libx264 -crf 17 -pix_fmt yuv420p out.mp4
```
obj: ribbon / heart / cake / lipstick / perfume / dresser / strawberry / cherry / macaron / all
ブラウザで `index.html?obj=cake` を開くとプレビューできる。
